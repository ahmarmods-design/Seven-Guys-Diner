==================================================
GOAL
==================================================

The restaurant owner must be able to manage the entire website without touching the source code.

Everything should be editable from the Admin Panel.

==================================================
MENU MANAGER
==================================================

Allow the owner to:

• Add new menu items

• Edit existing items

• Delete items

• Upload or replace product images

• Change product name

• Change description

• Change category

• Change price

• Change discount price

• Mark item as Featured

• Enable/Disable availability

==================================================
LIVE SYNCHRONIZATION
==================================================

The Admin Panel must be connected to persistent storage.

When the owner saves any change:

• The live website should update automatically within a few seconds.

• No code editing.

• No redeployment.

• No manual refresh.

• Visitors should see the updated content automatically.
